## Короткие ответы жюри

**Почему локальная обработка?** Для фиксированных полей и Положения она даёт воспроизводимый результат, координаты источников и не требует передачи документов во внешние сервисы.

**Откуда берутся значения?** Из пикселей через Tesseract; PDF сначала растрируется. Эталонный JSON читает только отдельный оценщик после получения результатов. Идентификатор документа не участвует в извлечении.

**Что будет с новыми значениями?** Три отдельно отрисованных документа с другими именами, датами и номерами проходят автотест. Это дополнительная проверка переноса, не обещание идеального распознавания всех снимков.

**Что именно значит 100%?** Macro accuracy полей, exact match комплектности и exact match структурированных ответов официального оценщика на 30 открытых документах / 120 вопросах. PNG и PDF — представления тех же документов, не 60 независимых случаев.

**Как запустить на закрытом наборе?** `python -m scripts.official_batch --package ПУТЬ --output results.json`. Установить Tesseract rus+eng; после установки сеть не требуется.
