# Эксплуатация локального продукта

## Перед демонстрацией

1. Открыть PowerShell в каталоге проекта и выполнить `start.ps1`.
2. Дождаться результата диагностики `ready: true` и запуска Uvicorn.
3. Открыть http://127.0.0.1:8000. Проверить один из встроенных сценариев или загрузить подготовленный документ.
4. Проверить, какая база правил подключена. По умолчанию подключено официальное Положение «Меридиана» 1.0.
5. Перед остановкой сервера скачать нужные результаты. Память сессий при остановке очищается.

## Передача результата

Кнопка «Пакет проверки» выгружает ZIP:

- `analysis.json`: значения, статусы, координаты, цитаты, копия правил, история ручных изменений.
- `report.html`: читаемый протокол; открыть в браузере, при необходимости напечатать в PDF.
- `pages/`: обработанные JPEG-страницы, к которым относятся координаты.
- `MANIFEST.json`: SHA-256 каждого включённого файла.
- `README.txt`: описание состава и ограничений.

Исходный файл не сохраняется сервером постоянно и не включается в пакет. Сохраните оригинал отдельно, если он нужен для дальнейшей проверки. Контрольные суммы не являются цифровой подписью.

## Ошибки и восстановление

| Ситуация | Действие |
| --- | --- |
| OCR требует настройки | Запустить `python -m scripts.doctor`, установить Tesseract и языки rus+eng по README. |
| Нет связи с сервисом | Проверить окно PowerShell и http://127.0.0.1:8000/api/ready. Перезапустить start.ps1. |
| Порт 8000 занят | Использовать уже запущенный экземпляр или остановить его Ctrl+C в его терминале. Не завершать неизвестные процессы. |
| Истекла сессия документа | Загрузить документ повторно; сохранить результаты до истечения 30 минут неактивности. |
| Истекла база правил | Импортировать Положение снова; существующий результат сохраняет свою копию правил. |
| OCR не успел обработать страницу | Разделить PDF, обрезать лишний фон, снять документ при ровном освещении. |
| Ошибка 429 | Дождаться завершения текущих задач: одновременно доступны два OCR-обработчика. |
| Не найден номер пункта | Текстовый импорт ожидает строки вида «1.1 Текст»; проверить OCR или использовать структурированный JSON. |
| Неверно прочитано поле | Открыть карандаш, сверить с оригиналом, сохранить исправление. Оно попадёт в историю как ручное. |

## Границы размещения

Один процесс Uvicorn, localhost, без постоянного хранилища и внешних API моделей. Максимум 12 сессий документов и 8 импортированных баз правил; старые записи вытесняются. Не запускать несколько workers: память между ними не разделяется. Нет аккаунтов, многопользовательских ролей и серверного резервного копирования.

Docker-конфигурация содержит непривилегированного пользователя, файловую систему только для чтения, временный каталог и healthcheck. Фактический запуск Docker не проверен: Engine на рабочем компьютере недоступен. Публичное развёртывание требует отдельной реализации авторизации и изоляции данных.

## Комплект для организаторов

Исходники и конфигурация упаковываются `python -m scripts.package_release`. Конкурсный batch генерируется `python -m scripts.official_batch --output results.json`. Полные команды и состав комплекта — в README.md. Материалы защиты версии 3 находятся в output/defense-v3 и output/demo-v3.
