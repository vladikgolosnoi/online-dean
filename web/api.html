API Онлайн-деканата

Локальный HTTP API для анализа документов, уточняющих вопросов и выгрузки протоколов.

Быстрый запрос

curl.exe -F "file=@document.png" -F "question=Содержит ли документ все обязательные сведения?" -F "document_type=auto" http://127.0.0.1:8000/api/analyze

Ответ содержит идентификатор сессии, классификацию, поля с координатами источников, ответ и снимок применённых правил. Сессия действует 30 минут неактивности.

Общие правила

ФорматыPNG, JPG, JPEG, PDF
Ограничениядо 15 МБ, до 5 страниц PDF
Адрестолько localhost
